## 로컬에서 확인하기

```bash
cd web_hub
python3 -m http.server 8080
# http://localhost:8080/index.html
```

서버를 띄우지 않아도 `index.html`을 브라우저로 직접 열면 대부분 동작합니다(모든 링크가 상대 경로).

## 배포

| 서비스 | 방법 |
|---|---|
| **GitHub Pages** | 저장소에 `web_hub` 폴더 내용을 올리고 Settings → Pages → Branch 지정. `/repo-name/` 하위 경로에서도 CSS·링크가 그대로 동작하도록 모든 경로를 상대 경로로 작성했습니다. |
| **Cloudflare Pages / Vercel** | 빌드 명령 없이 output directory를 `web_hub`로 지정해 업로드. |
| **직접 서버** | 폴더를 그대로 웹 루트에 복사. |

현재 **https://biya-maker.github.io/** (GitHub Pages · `biya-maker/biya-maker.github.io` 저장소 `main` 브랜치)에 배포되어 있고, canonical·OG·sitemap·robots 주소도 루트에 맞춰 두었습니다.

## 이름·도메인 바꾸기 (가칭 → 실제 이름)

브랜드 이름은 공통 헤더/푸터/메타 블록에만 나타나도록 구조화해 두었습니다. 아래 3가지를 일괄 치환하면 됩니다.

1. `딴짓플레이` → 새 한글 이름
2. `Ddanjit Play` / `ddanjitplay` → 새 영문 이름·도메인
3. `ddanjitplay@gmail.com` → 새 문의 메일
4. 헤더의 `.brand-mark` 안 글자(`딴`)와 `assets/favicon.svg` 색/모양

```bash
cd web_hub
grep -rl "딴짓플레이\|ddanjitplay\|Ddanjit Play" . | xargs sed -i 's/딴짓플레이/새이름/g; s/ddanjitplay@gmail\.com/newmail@gmail.com/g; s/ddanjitplay/newdomain.com/g; s/Ddanjit Play/New Name/g'
```

브랜드 색을 바꾸려면 `assets/style.css`의 `:root` 변수(`--brand`, `--accent` 등)만 수정하세요.
